# 墨弈 · 水墨象棋

项目使用STEAM最新的稳定版本的GODOT

## 界面语言

右上角使用 `中文 / English` 下拉框切换语言。首次启动默认中文，偏好保存到 `user://语言偏好.cfg`，下次运行自动恢复。切换会更新标题、棋盘说明、操作说明、回合状态和配置错误，不会重开棋局或中断电脑搜索。棋子上的将、帅、士、仕等文字始终保持中文；较长的配置错误可在右侧滚动查看。

统一翻译入口为 `脚本/语言管理.gd`，中文和英文文本分别位于 `翻译/中文.tres` 与 `翻译/英文.tres`。新增玩家可见文本时（棋面文字除外），应同时补齐两份资源，动态句子的参数在翻译之后替换。

## 调整开局

在 Godot 文件系统中双击 `配置/默认开局.tres`，在检视器展开 `棋子列表` 列表：

- 新增或删除 `棋子配置` 条目来调整棋子数量。新增条目需选择“新建 棋子配置”。
- `阵营`：黑方、红方；`棋种`：将帅、士仕、象相、马、车、炮、兵卒。
- `棋盘位置` 为交叉点坐标，左上 `(0, 0)`、右下 `(8, 9)`。黑方底线为 y=9，黑卒向 y 递减方向前进；红方相反。
- `血量` 配置初始及最大血量；`玩家阵营` 配置玩家阵营；`先手阵营` 配置先手方。

保存资源后点击游戏“重新开局”会从磁盘重新加载开局资源。也可新建 开局配置 资源，在 `场景/主场景.tscn` 根节点的 `开局` 字段指定。新建资源需保存为 `.tres`，各开局布局可以独立复用。

坐标不可重叠或越界，血量须大于零，双方各需一个九宫内的将帅，开局不可将帅照面。其他棋子允许自由布置，但行动时仍遵守棋种限制。配置错误会在游戏右侧显示并阻止开局。

## 血量规则

攻击扣一血且消耗回合。目标存活时双方位置不变，目标死亡时攻击者占据目标位置。所有棋子包括将帅都可配置多血量。将帅只有面对下一次攻击就会死亡的威胁时才算将军，非致命攻击后按剩余血量重新判定；将帅照面始终禁止。默认全员一血时与常规象棋吃子和将军行为一致，默认黑方先手是本作的设置。

初版不裁定长将、长捉或重复局面和棋。电脑使用两层搜索；重开后旧搜索结果会被丢弃。棋盘、装饰和棋子均为代码绘制，可直接调色和缩放，无外部图片依赖。字体优先使用系统楷体，回退到可用的中文系统字体。

## 验证

```powershell
godot --headless --path . --editor --quit
godot --headless --path . --script res://测试/规则测试.gd
godot --path . --script res://测试/场景测试.gd
```

最后一项检查场景交互、AI、重开与缩放，并生成 `验证产物/棋盘预览.png` 和 `验证产物/小窗口棋盘.png`。


## 中文命名约定

游戏自定义目录、场景、脚本、节点、类、方法、变量、枚举和配置字段使用中文。主要逻辑位于 `脚本/主场景.gd`、`脚本/象棋规则.gd` 和 `脚本/象棋电脑.gd`；棋子状态字段为 `编号、阵营、棋种、坐标、当前血量、最大血量`，行动字段为 `编号、目标`。

本次直接迁移了项目内的开局资源。另存于项目外的旧资源需要同步迁移字段及脚本路径后使用。阵营枚举顺序仍为黑方 0、红方 1，棋种顺序仍为将帅、士仕、象相、马、车、炮、兵卒。

Godot 固定文件名、内置类型、属性、回调、主题键和系统字体名保持原样，例如 `project.godot`、`_ready`、`position`、`font_size`。资源内部 ID 仅允许字母、数字和下划线，因此保留 `Piece_1` 等内部 ID；UID 保持原值。手动编辑 `.tres` 或 `.tscn` 时，中文属性名必须用双引号包围，例如 `"棋子列表" = ...`，建议通过检视器保存资源。

场景测试使用独立的 `user://测试语言偏好.cfg`，不会覆盖实际语言设置。测试覆盖语言偏好恢复、译文完整性、动态文案、配置错误、选中状态保留、思考期间切换，以及两种语言的多分辨率截图；截图与检查日志保存在 `验证产物/`。
